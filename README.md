```

https://gh-proxy.org/https://github.com/Newera2625/newera-products/releases/download/v1.0.0/SevenEndpoint_Setup.exe

https://gh-proxy.org/https://raw.githubusercontent.com/Newera2625/newera-products/main/<路径>
```
